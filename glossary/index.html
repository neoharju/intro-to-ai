Reference90 terms · weeks 1–7

Glossary

Short definitions of the main terms of the course, each with a link to the section that introduces it. To find every place where a term is used, search the material (Ctrl+K, or ⌘K on a Mac).

A B C D E F G H I K L M N O P Q R S T V X

A

A* search

Best-first search that always expands the state with the smallest estimated total cost: the cost of the path so far plus a heuristic estimate of the cost from there to the goal. With an admissible heuristic, the path it finds is optimal.

Week 1: Informed search and A*

Activation function

The function that a neuron applies to its weighted sum, such as ReLU, the sigmoid or tanh. It has to be nonlinear: without it, any number of layers computes no more than a single linear map.

Week 4: Why nonlinear activations are essential

Admissible heuristic

A heuristic that never overestimates the true cost from a state to the goal.

Week 1: Informed search and A*

Agent

Anything that perceives its environment through sensors and acts on it through actuators. A rational agent chooses the action that it expects to do best by its performance measure, given what it knows.

Week 6: Rational action under limited information

AGI (artificial general intelligence)

A hypothetical AI system that could do most of the cognitive tasks that people can, at least as well as people, instead of one narrow task.

Week 1: Narrow AI, general-purpose models and AGI

AI winter

A period of reduced funding, investment and confidence in AI after expectations were disappointed: roughly the mid-1970s to the early 1980s, and the late 1980s to the mid-1990s. Research did not stop.

Week 1: AI winters: when expectations exceeded results

Alpha-beta pruning

Minimax that skips the branches that cannot change the result, using the values that each player is already guaranteed (α for Max, β for Min). It returns the same value as minimax with less work, the more so the better the moves are ordered.

Week 1: Alpha-beta pruning

Attention

A layer that computes each output as a weighted average of value vectors. The weights, a softmax of the dot products of a query with the keys, say how relevant each position is.

Week 5: Attention layer

Autoencoder

A network trained to reproduce its input through a narrow middle layer, which makes it learn a compact code of the data without any labels.

Week 4: Autoencoders: learning without class labels

B

Backpropagation

The algorithm that computes the gradient of the loss with respect to every weight of a network, layer by layer from the output back to the input, with the chain rule.

Week 4: Backpropagation: calculating which changes would reduce loss

Bagging

Bootstrap aggregating: every model of an ensemble is trained on a bootstrap sample of the training data (drawn with replacement), and their predictions are averaged or put to a vote. It reduces variance.

Week 3: Bagging

Bayes rule

P(A | B) = P(B | A) P(A) / P(B). It turns the probability of the evidence given a hypothesis into the probability of the hypothesis given the evidence.

Week 2: Bayes rule and probabilistic inference

Bayesian network

A directed acyclic graph whose nodes are random variables. Every node has a conditional probability table given its parents, and the product of these tables is the joint distribution of all the variables.

Week 3: Building blocks of a Bayesian network

Bellman equation

The value of a state is the expected immediate reward plus the discounted value of the next state. Value functions and Q-learning rest on it.

Week 6: Why value functions help with delayed reward

BERT

An encoder-only Transformer, pretrained to predict masked words from the words on both sides of them. It is used for tasks that need understanding, such as classification.

Week 5: BERT and GPT

Boosting

Trains weak models one after another, each concentrating on the errors that the models before it still make, and adds them up into one strong model.

Week 3: Boosting

Breadth-first search

Explores the states in the order of their distance from the start (a first-in, first-out queue). It finds a path with the fewest steps, but keeps the whole frontier in memory.

Week 1: Breadth-first and depth-first search

C

Chinese room

Searle's thought experiment: a person who answers Chinese questions by following a rule book can give correct answers without understanding Chinese. Running a program (syntax) is therefore not enough for understanding (semantics).

Week 1: Searle: syntax is not automatically semantics

Classification

Supervised learning in which the output is a category, such as spam or not spam.

Week 3: Problem formulation

Conditional probability

P(A | B), the probability of A when B is known to be true: P(A and B) / P(B).

Week 2: Probability fundamentals

Conditional probability table (CPT)

In a Bayesian network, the probabilities of the values of a node for every combination of the values of its parents.

Week 3: Building blocks of a Bayesian network

Convolutional neural network (CNN)

A network for grid data such as images. Its layers slide small filters with shared weights across the input, so that a pattern is found wherever it is.

Week 4: Why images motivate convolutional networks

D

Decision tree

A tree of tests on the features: an example goes from the root down to a leaf, which gives the prediction. It is grown greedily, choosing at each node the test with the highest information gain (or a similar criterion).

Week 3: Decision trees

Depth-first search

Follows one path as deep as possible before backing up (a last-in, first-out stack). It needs little memory but can find long paths, and without a record of the visited states it can loop.

Week 1: Breadth-first and depth-first search

Discount factor

The number γ between 0 and 1 that weights a reward k steps ahead by γk, so that a reward now counts more than the same reward later.

Week 6: Why introduce a Markov decision process?

E

Embedding

A learned vector that represents a discrete item, such as a word or a token, so that similar items get nearby vectors.

Week 4: From discrete identifiers to learned embeddings

Ensemble

A model that combines the predictions of several models. Bagging, random forests, boosting and stacking make ensembles.

Week 3: Ensembles in machine learning

Entropy

A measure of uncertainty. For class proportions p1, …, pk it is −Σ pi log2 pi: 0 when all examples have one class, log2 k when all classes are equally common.

Week 3: Entropy

Epoch

One pass through the whole training set.

Week 4: Epochs, batches and optimizers

EU AI Act

The regulation of the European Union on AI systems (2024). It sorts them by risk: unacceptable-risk practices are prohibited, high-risk systems must meet strict requirements, limited-risk systems have transparency duties, and minimal-risk systems no specific ones.

Week 7: EU AI Act

Explainable AI (XAI)

Methods that show what a prediction of a model rests on, for example which features changed it the most.

Week 7: Explainable AI: what does the model actually use?

Exploration and exploitation

The choice of an agent that learns by acting: exploit the best action known so far, or explore others that may turn out better. An ε-greedy agent explores with probability ε.

Week 6: Why learning requires exploration

F

Fine-tuning

Training a pretrained model further on a smaller dataset, for a particular task.

Week 5: Transfer and adaptation

Forward propagation

Computing the output of a network from its input, layer by layer.

Week 4: Multilayer networks and forward propagation

Foundation model

A large model pretrained on broad data, usually without labels (self-supervised), that can be adapted to many tasks.

Week 5: From task-specific models to foundation models

G

Game tree

The positions of a game as a tree: the root is the current position, the children of a node are the positions after each legal move, and the leaves are the final positions with their values.

Week 1: Game trees

GAN (generative adversarial network)

Two networks trained against each other: a generator that turns random noise into fake examples, and a discriminator that tries to tell them from real ones.

Week 5: Generative adversarial networks

Generalization

How well a model does on new data that it was not trained on: the aim of learning.

Week 4: Learning the training set is not the same as learning the task

Generative model

A model of how the data are distributed, which can generate new examples (and, for some models, say how probable an example is).

Week 5: Generative models

GOFAI

Good Old-Fashioned AI: the symbolic approach that represents knowledge with explicit symbols and rules and reasons by manipulating them.

Week 1: Good Old-Fashioned AI (GOFAI) versus modern AI

GPT

A decoder-only Transformer, pretrained to predict the next token from the tokens before it. It generates text one token at a time.

Week 5: BERT and GPT

Gradient descent

Minimizes a loss by moving the parameters again and again a small step (the learning rate) against the gradient. Stochastic gradient descent takes the gradient of a mini-batch instead of the whole training set.

Week 3: Model and learning algorithm · Week 4: Epochs, batches and optimizers

H

Hallucination

An output of a generative model that is fluent and convincing but false, or not supported by its sources.

Week 7: AI “hallucinations”, or convincing but inaccurate outputs

Heuristic

A rule of thumb. In search, an estimate of the cost from a state to the goal, used to decide which state to expand first.

Week 1: Informed search and A*

Heuristic evaluation function

An estimate of the value of a game position, used when minimax stops at a depth limit before the end of the game.

Week 1: Depth-limited minimax and heuristic evaluation criteria

High-risk AI system

In the EU AI Act, a system used where it can seriously affect health, safety or fundamental rights, for example in hiring, education or credit scoring. It must meet requirements on risk management, data, documentation and human oversight.

Week 7: High-risk AI systems (Chapter III)

I

Information gain

How much a split reduces entropy: the entropy before the split minus the weighted entropy of the parts.

Week 3: Information gain

K

k-nearest neighbours (k-NN)

Predicts from the k training examples that are closest to the new example: their most common class, or the average of their values.

Week 3: K-nearest neighbors (KNN) algorithm

KV cache

In a Transformer that generates text, the stored keys and values of the earlier tokens. Each new token then needs the query, key and value of that token only, instead of those of the whole sequence.

Week 5: Why generation is fast: the KV cache

L

Latent space

The space of the internal codes of a model. In a generative model, points of it map to examples, and nearby points to similar examples.

Week 5: Interpolations in latent space

Learning rate

The size of the step that gradient descent takes against the gradient: too small and learning is slow, too large and it does not settle.

Week 4: Epochs, batches and optimizers

Linear regression

Predicts a number as a weighted sum of the features plus a constant. The weights are usually chosen to minimize the squared error on the training data.

Week 3: Mathematical formulation

Logistic regression

A linear classifier that turns the weighted sum of the features into a probability with the sigmoid function.

Week 3: Logistic regression

Loss function

A number that measures how wrong the predictions are, such as the squared error or the cross-entropy. Training minimizes it.

Week 4: What is the network trying to minimize?

M

Markov decision process (MDP)

A model of sequential decisions: states, actions, transition probabilities, rewards and a discount factor. The next state depends only on the current state and action (the Markov property).

Week 6: Why introduce a Markov decision process?

Minimax

Computes the value of a game position when both players play their best: Max takes the largest value of the children, Min the smallest.

Week 1: Minimax algorithm

Monte Carlo inference

Estimating a probability by drawing many random samples from a model and counting how often the event happens.

Week 3: Approximate inference (Monte Carlo)

Multi-agent system

Several agents that act in a shared environment, cooperating or competing; what they do together can differ from what any one of them does.

Week 6: Multi-agent systems

Multi-head attention

Several attention layers (heads) side by side, each with its own projections of the queries, keys and values, so that each can attend to a different kind of relation; their outputs are joined.

Week 5: Multi-head attention

Multilayer perceptron (MLP)

A network of layers of neurons with nonlinear activations, each layer feeding the next. With a hidden layer it can learn decision boundaries that are not straight, such as XOR.

Week 4: Multilayer networks and forward propagation

N

Naive Bayes classifier

Classifies with Bayes rule, assuming that the features are conditionally independent given the class.

Week 2: Naive Bayes classification

Narrow AI

AI built for one task or a narrow range of tasks, such as playing chess or recognizing speech.

Week 1: Narrow AI, general-purpose models and AGI

O

Overfitting

Fitting the training data, noise included, so closely that the model does worse on new data.

Week 3: Model selection and overfitting · Week 4: Learning the training set is not the same as learning the task

P

PEAS

A way to specify the task of an agent: its Performance measure, Environment, Actuators and Sensors.

Week 6: Specifying a task with PEAS

Perceptron

A single neuron: a weighted sum of the inputs plus a bias, followed by a threshold. Its learning rule moves the decision boundary after each mistake.

Week 4: The perceptron as an adjustable decision boundary

Policy

The rule by which an agent chooses its action in each state: a mapping from states to actions, or to probabilities of actions.

Week 6: From the model to the objective: policies and return

Positional encoding

Information about the position of each token, added to its embedding, because attention by itself does not see the order of the tokens.

Week 5: Attention layer

Prior and posterior

The prior is the probability of a hypothesis before the evidence; the posterior is its probability given the evidence, by Bayes rule.

Week 2: Bayes rule and probabilistic inference

Q

Q-learning

Learns the value Q(s, a) of taking action a in state s from single transitions: after each step, Q(s, a) moves toward the reward plus the discounted value of the best action in the next state. It needs no model of the environment.

Week 6: Q-learning: learning an action-value estimate from one transition

Query, key and value

The three vectors that attention computes from each token: the query of a position is compared with the keys of all positions, and the resulting weights average their values.

Week 5: Attention layer

R

Random forest

Bagging of decision trees in which each split considers only a random subset of the features, which makes the trees more different from each other.

Week 3: Random forest

Recurrent neural network (RNN)

A network that reads a sequence one element at a time and carries a hidden state from one step to the next.

Week 4: Why sequence order changes the problem

Regression

Supervised learning in which the output is a number, such as a price.

Week 3: Problem formulation

Reinforcement learning

Learning to act from rewards: the agent is not told the correct action but finds out by trying, and its actions can pay off only much later.

Week 6: Reinforcement learning: why actions require a different learning problem

ReLU

The activation function max(0, x): zero for a negative input, the input itself otherwise.

Week 4: Why nonlinear activations are essential

RLHF

Reinforcement learning from human feedback: people compare the answers of a language model, a reward model learns their preferences, and reinforcement learning tunes the language model toward answers with a high reward.

Week 6: How human feedback connects RL to language models

ROC AUC

The area under the ROC curve of a classifier: the probability that a randomly chosen positive example gets a higher score than a randomly chosen negative one (0.5 is guessing, 1 is perfect).

Week 3: What the Kaggle score measures: ROC AUC

S

Self-attention

Attention in which the queries, keys and values all come from the same sequence, so that the representation of each token takes in the context of the whole sequence.

Week 5: Attention layer

Sigmoid

The function 1 / (1 + e−x), which squashes any number into the interval from 0 to 1. Logistic regression uses it to turn a score into a probability.

Week 3: Logistic regression

Softmax

Turns a vector of scores into probabilities: each score is exponentiated and divided by the sum of them all.

Week 4: Why nonlinear activations are essential · Week 5: Attention layer

Stacking

An ensemble in which a meta-model learns to combine the predictions of several base models, trained on their out-of-fold predictions.

Week 3: Stacking

State space

The states of a search problem, with the actions that lead from one to another. Solving the problem means finding a path from the start state to a goal state.

Week 1: Formulating problems as search

Supervised learning

Learning a function from examples whose correct outputs (labels) are given.

Week 3: Problem formulation

T

Test set and validation set

Examples kept out of training. The validation set is used to choose between models and settings; the test set only at the end, to estimate how well the chosen model works on new data.

Week 3: Model selection and overfitting

Token

A unit of text that a language model reads and writes: a word, a piece of a word or a character, which a tokenizer maps to a number.

Week 5: From tokens to contextual predictions

Transformer

A neural network built of blocks that each have a self-attention layer and a feed-forward network, with residual connections and layer normalization. Today’s language models are Transformers.

Week 5: Inside the Transformer block

Turing test

Turing’s imitation game: a machine passes if a human judge, conversing with it and with a person in text, cannot reliably tell which is which.

Week 1: Turing: operationalizing intelligent behaviour

V

Value function

The expected return from a state (or from a state and an action: the Q-function) when the agent follows a given policy.

Week 6: Why value functions help with delayed reward

Vision Transformer (ViT)

A Transformer for images: the image is cut into patches, and each patch is treated as a token.

Week 5: Transformers beyond text

X

XOR problem

XOR is not linearly separable, so a single perceptron cannot learn it; a network with a hidden layer can.

Week 4: Why one neuron cannot solve XOR
