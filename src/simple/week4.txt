== 338ba898
A neural network is a function with parameters. We make it from a sequence of simpler functions. Training changes the parameters, so that the outputs become useful for a task. This week has three important questions: <b>What can a network represent? How can it learn its parameters? How do we know that it learned something useful, also for examples that it did not see in training?</b> We use one example through the week: the recognition of handwritten digits. Small numerical examples show the calculations.

== 80e18c69
The word <i>neuron</i> is a mathematical analogy (a comparison). It does not mean that these models copy a biological brain. The architecture, the training objective and the data of a network set what it can learn. A large number of parameters alone does not explain intelligence, understanding or reliable behaviour.

== 25d1f6bf
Neural networks did not start with the large language models of today. They started when researchers tried to connect mathematical models of computation, learning and nervous systems. The history includes logical threshold units, classifiers that can learn, associative memories, self-organizing maps and deep representation learning. These research traditions overlap. They are not a simple sequence where each new model replaces all the models before it.

== 628ab1ae
<b>Be careful with the history:</b> it is not correct to say that one “AI winter” started in 1960. It is also not correct to say that one book caused a full decrease in research. AI funding and the interest in neural networks changed at different times, for different reasons. Also, no single person or paper made all parts of backpropagation. Reverse-mode differentiation, its use for learning and its popularity each have a different history.

== 2083e5d2
The useful part of the analogy is this: many connected units can make complex behaviour, and a change of their connections can change this behaviour. A biological neuron is a living cell with dendrites, a cell body and an axon. Signals come in through synapses and change the activity of the cell. Many neurons send action potentials (electrical pulses) along the axon. At the synapses, they communicate with chemicals. The artificial unit keeps only a small part of this: inputs, connection weights that can change, a sum and an output function.

== 08efb036
Brains have many recurrent connections (connections that go back), many types of cells and interactions on many time scales. Artificial networks can be feedforward, recurrent, probabilistic or spiking. Thus, these two statements are not always true: “natural networks are binary, but artificial networks are continuous” and “artificial networks have no feedback”. A spike is an event. But the firing rate, the time of the spikes and other biological variables also carry information.

== b1f8579b
<b>Connection to computation:</b> neural computation is parallel, and it adapts. A simple program is different: it does one instruction after the other. But this difference does not show that neural networks can calculate functions that a Turing machine cannot calculate. Most networks in this course are numerical programs on usual digital hardware. Also, a design that comes from the brain is not automatically evidence of consciousness or human-like understanding.

== b3d2fdb9
<b>Biology reference:</b> the US National Institute of Neurological Disorders and Stroke, <a href="https://www.ninds.nih.gov/publications/know-your-brain-brain-basics" target="_blank" rel="noopener">Know Your Brain</a>. The comparison diagram on this page is a simple drawing for teaching concepts. It is not a correct model of the anatomy or of the mechanisms of the brain.

== 6ce88ffa
A Hopfield network is an example of recurrent dynamics. Its state changes over time, and it can find a stored pattern from a cue (a start pattern) that is partial or damaged. Under suitable conditions, an energy function helps to analyze convergence. But this does not mean that each cue finds the correct memory. A Boltzmann machine uses random (stochastic) units in a probabilistic model that is based on an energy. A self-organizing map uses a different idea. The prototype that wins, and the prototypes near it, move toward an input. Thus, the map puts similar inputs near each other on a grid. These examples show that neural computation is more than supervised feedforward classification. They give context. You do not have to implement them this week.

== c381a5eb
An image of a handwritten digit can have 28 by 28 grayscale pixels. A fully connected network can get it as a vector of 784 numbers. A pixel value is a measurement. It is not an instruction such as “this is the upper loop of an eight.” The model must learn which combinations of measurements are useful. A training example is a pair: an input <span class="math">x</span> and a target <span class="math">y</span>, for example the digit label 8.

== e9533221
A training dataset has many of these pairs. When the model makes a prediction, it gets a new image without the correct label. Thus, its parameters must contain a rule that works for different handwriting, line thickness and position. A table of the images that it saw before is not sufficient. Features such as the pixel scale and the image resolution must be the same in training and in later use.

== 26e965f7
<b>Preprocessing:</b> MNIST pixels usually have values from 0 to 255. Divide by 255 to change them to the interval <span class="math">[0, 1]</span>. For other numeric features, standardization (a change of each feature to mean 0 and standard deviation 1) can help the optimization. If the preprocessing uses values from the data, calculate these values only from the training split. The input representation and the preprocessing are parts of the model pipeline.

Here <span class="math">w</span> is the current weight vector and <span class="math">w'</span> is the new vector. <span class="math">x</span> is the current input, <span class="math">y</span> is the true label, <span class="math">\hat{y}</span> is the predicted label, and <span class="math">\lambda &gt; 0</span> is the learning rate. == af3725cd
Here we use the labels 0 and 1, so the error term is −1, 0 or +1. The same formula also works with the labels −1 and +1. But then an incorrect prediction gives −2 or +2. Thus, the step size depends on the label convention and on <span class="math">\lambda</span>. Many texts use the update <span class="math">w' = w + \alpha\, y\, x</span> after a mistake, with signed labels. This update is the same when <span class="math">\alpha = 2\lambda</span>.

== 32f12d87

== 34e339bf
This rule corrects the errors of a perceptron. It is not a training formula for all neural networks. A sigmoid output with binary cross-entropy has a similar gradient update for one example: the error times the input, where <span class="math">\hat{y}</span> is a probability. Hidden layers also need the derivatives that backpropagation calculates.

== bddbe2a4
The perceptron learning rule converges: after a finite number of errors, it finds a line that separates the classes. This is true when a finite dataset is linearly separable and the usual assumptions of the convergence theorem are true. When the classes overlap, or when they need a nonlinear boundary, maybe no separating weights exist. More training cannot correct a limit of the model family.

== c9b7b77b
<b>Activity:</b> try to draw one line that separates the diagonal pairs. The first unit finds if one or two inputs are 1. The second unit finds if the two inputs are 1. The output <span class="math">\operatorname{step}(h_1 - 2h_2 - 0.5)</span> gives XOR.

== cb617386
The four inputs become <span class="math">(0, 0)</span>, <span class="math">(1, 0)</span>, <span class="math">(1, 0)</span> and <span class="math">(1, 1)</span>, in this sequence. The two positive examples now have the same hidden representation <span class="math">(1, 0)</span>. The output can separate it from the negative examples. We set these weights by hand, to show what the network can represent. It is a different problem to train a network so that it finds useful hidden features.

== fb890b7a
The perceptron predicts +1 when <span class="math">w \cdot x + b \ge 0</span>. If not, it predicts −1. It goes through the examples in a fixed sequence. After each mistake, it applies the learning rule above with <span class="math">\lambda = 0.5</span>. With the labels −1 and +1, a mistake gives <span class="math">y - \hat{y} = \pm 2</span>. Thus, the update adds <span class="math">y\,x</span> to <span class="math">w</span> and <span class="math">y</span> to <span class="math">b</span>. On linearly separable data, the mistakes stop after a finite number of updates. On XOR, the mistakes never stop.

== ce441fc5

Its first weight matrix has the shape <span class="math">40 \times 784</span>, and its first bias vector has the length 40. The second matrix has the shape <span class="math">10 \times 40</span>, and the output bias vector has the length 10. Thus, the network has <span class="math">784 \times 40 + 40 + 40 \times 10 + 10 = 31{,}810</span> parameters that training can change. The input layer only holds the data. == 60e95a86
More <b>width</b> adds units in a layer. More <b>depth</b> adds transformations, which can use the earlier representations again. Neither of them makes the test performance better for certain. A deep network can represent some functions much more compactly. But the data, the stability of the training and the architecture are also important. A hidden unit does not always show a concept that a person can easily name.

== 78a25808
Backpropagation multiplies by the derivative of the activation function. The derivative of the step function is zero at all points except 0, where it has no value. Thus, it gives no gradient for learning. The derivative of the sigmoid is <span class="math">\sigma'(z) = \sigma(z)\bigl(1 - \sigma(z)\bigr)</span>. Its maximum value is 0.25. The derivative of tanh is <span class="math">1 - \tanh^2 z</span>. Its maximum value is 1. The derivative of ReLU is 0 for negative inputs and 1 for positive inputs.

== e90e1863
The hidden activations and the output function can be different. A regression model can use a numeric output with no limits. Binary classification frequently uses a sigmoid. Digits have ten classes, and only one class can be correct. For them, <b>softmax</b> changes ten scores (logits) into values that are not negative and that have the sum 1. A large softmax value can be wrong, or it can be poorly calibrated. It does not make sure that the prediction is correct.

== a3f82447
A <b>loss function</b> measures the difference between the output and the target. For a regression example with one number as the prediction <span class="math">\hat{y}</span>, we can use <span class="math">L = \tfrac{1}{2}(\hat{y} - y)^2</span>. For binary classification, cross-entropy gives a large loss when the probability <span class="math">p</span> of the correct label is low:

== 4381fc01
If the correct class gets the probability 0.8, the multiclass loss is approximately 0.223. At the probability 0.2, it is approximately 1.609. Thus, the loss shows a difference between two predictions, also when they select the same top class. Accuracy counts the correct classifications. The loss gives a learning signal with many levels. In libraries, cross-entropy frequently accepts logits. It then does the output transformation and the logarithm in one operation that is numerically stable.

== 2dc3c8a8
The objective is usually the average loss over the examples, sometimes with a regularization term. The objective is a design decision. Bad labels or a bad objective can give a model that optimizes the training task, but does not help with the real-world purpose.

A positive derivative means this: a small increase of the parameter increases the loss. Thus, gradient descent moves the parameter in the opposite direction, with the learning rate <span class="math">\eta</span>:

== 949fc837

== 6d268115
<b>Backpropagation</b> calculates the gradients efficiently. It applies the chain rule through the computation graph. It uses the intermediate results from the forward pass again, and it sends the sensitivities backward. Then the <b>optimizer</b> uses the gradients to change the parameters. Backpropagation and gradient descent are different operations, but both occur during training.

== c2edd9aa
Random start values break the symmetry. If all units in a hidden layer start with the same values and get the same updates, they can continue to learn the same feature. Initialization methods such as Xavier/Glorot and He initialization select a scale for the start values. The scale helps the signals and the gradients to stay useful through all layers. A random seed makes it easier to get the same result again. But some hardware and software operations can still give small differences.

== 1e2b1a0b
<b>Episode 7 checkpoint:</b> explain the function of each arrow in the training diagram. Which operation uses labels? Which operation calculates derivatives? Which operation changes the weights? At usual inference time (when the model makes predictions), a trained classifier does a forward pass. It does not use training labels, and it does not change its parameters.

== f4df032b
An <b>epoch</b> is one pass through the training examples. A <b>mini-batch</b> is a group of examples. We use it to estimate the gradient for one parameter update. With 6,000 training examples and the batch size 100, one epoch usually has 60 updates. Eight epochs have approximately 480 updates, not eight. The training loss is frequently noisy, because different batches have different examples.

== 70831713
Full-batch gradient descent uses the full training set for one update. Stochastic gradient descent with single examples makes an update after each example. Mini-batches are a practical compromise: the computation is efficient, and the gradient is a noisy approximation of the full gradient. A larger batch changes how the optimization behaves and how many resources it uses. It does not automatically give better generalization.

== c0b5f096
<b>Learning rate:</b> if it is too small, the progress can be too slow for practical use. If it is too large, the steps can go past the minimum or diverge, as the worked example showed. A schedule changes the learning rate over time. Momentum collects information from the previous gradients. Adam keeps moving averages of the gradients and of their squares, and it adapts the updates with them. With all optimizers, you must still examine the data, the loss and the validation results.

== ad9a3a6f
<b>The training foundations are now earlier in the course:</b> before, Week 5 introduced these concepts together with the details of Transformers. But they also apply to usual networks. Week 5 uses them again for gradient accumulation, learning-rate schedules and training at a large scale.

== 4c02dd1a
The <b>training set</b> gives the examples that change the parameters. The <b>validation set</b> helps you to make decisions, for example about the model size, the learning rate and when to stop training. The <b>test set</b> estimates the performance of the pipeline that you selected. If you select architectures many times with the test scores, the test set becomes another validation set. Then the result that you report can be too optimistic.

== 2c5d2439
For digit recognition, keep all copies and augmentations of one original image in the same split. In other applications, split the data by person, by device or by time, when this agrees with the planned use. If you separate adjacent sensor readings at random, almost the same observations can go into different splits (leakage). A high test score on one distribution does not show robustness to a new camera. It also does not show robustness to the handwriting of a new group of people.

== 22911ff8
These curves are examples. They are not measurements from an experiment. <b>Underfitting</b> means that the model cannot learn the important patterns of the training data well. <b>Overfitting</b> occurs when the training performance becomes better, but the performance on new data does not. When the training loss decreases and the validation loss increases, this is a useful warning sign. But it is not a diagnosis that is always correct.

== ffc1b3f1
<b>L2 regularization</b> adds a penalty for the squares of the weights. Its strength is a hyperparameter.

== 7a3efda5
<b>Early stopping</b> selects a checkpoint (a saved state of the model) with the validation performance, not with the lowest training loss.

== 22b75428
<b>Dropout</b> sets some activations to zero at random during training. For predictions, the network uses the related inference-time rule. It does not remove units at random in the same way.

== 35e90686
<b>Data augmentation</b> makes realistic variations of the data, for example small shifts of digit images. Do not use a transformation that changes the correct label.

== d0782ace

== 8fb2fca4
A fully connected layer uses a separate input connection for each pixel position. But a small pattern, for example the corner of a stroke, can occur in many positions. A <b>convolutional layer</b> uses the same learned filter at different locations in the image. Local connections and shared weights contain a useful assumption: the same local pattern can be important at all positions.

== 35623948
When the filter moves over a larger image, it makes a feature map. Technically, this usual deep-learning operation is cross-correlation. But software usually calls the layer a convolution.

== 234bd0b4
<b>Compare the parameters:</b> an RGB filter with the height 3 and the width 3 has <span class="math">3 \times 3 \times 3 + 1 = 28</span> parameters, with its bias. Sixteen of these filters have 448 parameters. This number does not change with the number of locations where you apply them. But the feature maps can still be large. Thus, fewer parameters does not mean very little computation or memory.

== 8bc79cc5
The <b>stride</b> controls the distance that the filter moves between two locations. <b>Padding</b> adds a border, to control the output size. Pooling makes a summary of each local area and decreases the spatial resolution. Convolutions with a stride larger than 1 can also decrease the resolution. These operations can make the network more tolerant of small shifts. But a CNN is not automatically invariant to all translations, rotations or changes of the viewpoint.

== 1870c0ff
A typical CNN for digits learns some feature maps, combines them in later layers and gives class scores. Early filters can react to simple strokes. Later patterns can combine evidence from larger areas. This is an architectural bias (an assumption in the design). It does not make sure that each hidden unit has a clear meaning for people. <b>Connection to Week 5:</b> Vision Transformers use image patches and attention, not exactly this design with local filters. When you understand CNNs, you can understand this difference.

== 0234d297
The identifier (ID) of a word or token is arbitrary. If “cat” has the ID 12 and “dog” has the ID 13, their meanings are not similar because the numbers are near. A one-hot encoding does not have this incorrect sequence. But it uses one coordinate for each item in the vocabulary. An <b>embedding table</b> gives each item a learned vector with a dimension that you select. When you look up a token, you select one row of this table.

== a8465248
A vocabulary of 10,000 tokens with 50-dimensional embeddings has 500,000 embedding parameters. The training task gives the signal that moves these vectors. Thus, context prediction, classification and recommendation can learn different types of similarity. The vectors do not get their meaning from the names of their coordinates. If you rotate the full space, the geometry between the pairs of vectors stays the same.

== c9cc68c7
For example, <span class="math">u = (1, 0)</span> and <span class="math">v = (1, 1)</span> have the cosine similarity <span class="math">1/\sqrt{2} \approx 0.707</span>. A value near 1 shows similar directions. It does not always mean that you can use one word in place of the other. Antonyms (words with opposite meanings) can occur in the same contexts, and their vectors can be near. Similarity is a learned association. It is not a universal measure of meaning.

== ab1496a8
Static embeddings give “bank” one vector, also when it means a river bank or a financial institution. Contextual networks calculate a different representation for each occurrence. The drawing above shows an example of a projection. It is not measured evidence that categories of meaning make tidy two-dimensional clusters. Embeddings can also show the biases or the gaps in their training data.

== 56538d64
“The dog chased the child” and “The child chased the dog” have the same words, but they describe different events. If you calculate the average of static word embeddings, you lose this sequence. A recurrent neural network (RNN) processes a sequence. It updates a hidden state again and again:

== 9739c731
It uses the same parameters at all positions. The hidden state depends on the inputs before the current position.

== cb66af13
The state is a learned summary. It is not a perfect memory. Through long sequences, the gradients can become very small or very large. Thus, it is difficult to learn dependencies over long distances. Gated architectures such as LSTMs and GRUs solve parts of this problem, but not all limits. This is an introduction to the concepts. You do not have to implement the gates this week.

== 0bfae681
<b>Bridge to attention:</b> an RNN must send each important detail through one recurrent state. Attention does not do this. It lets a representation combine information from selected positions. In <a href="../week5/">Week 5</a>, query–key scores set these combinations. Transformers also need information about positions, because a set of token vectors alone does not show the sequence. CNNs, RNNs and attention use different assumptions about how to combine information. They are not only larger and larger versions of the same model.

== 7689f661
Representation learning does not have to predict a class. An <b>autoencoder</b> changes an input into a code with an encoder, <span class="math">z = \operatorname{encoder}(x)</span>. Then it makes the input again (it reconstructs it) with a decoder, <span class="math">\hat{x} = \operatorname{decoder}(z)</span>. The training target comes from the input. It is not a digit category that a person gives. A reconstruction loss measures the difference between the original data and the reconstructed data.

== ef2e352d
A bottleneck (a small code), a denoising objective or another constraint can prevent simple copying. For example, a 16-dimensional code must make a summary of a 784-dimensional image in a small space. This code can keep the style of the strokes and the identity of the digit, because both help the reconstruction. It is not always the best representation for classification. A network that is very flexible and has no constraints can learn the identity mapping (it only copies the input), which is not useful.

== 32eaf6ad
A standard autoencoder <b>does not automatically make realistic new images</b>. Random points in its code space can give bad images after the decoder. Models such as variational autoencoders add more structure, so that sampling works. Here we introduce the ideas of encoder–decoder and latent code, before the generative models of Week 5. The graded autoencoder exercise stays in <a href="../week5/#exercises">Week 5</a>.

== f2605fdc
<code>MLPClassifier</code> and Keras do the training loop for you, so you do not see it. The <a href="#backprop-example">numerical backward pass</a> above applied the chain rule by hand to one hidden unit. Here is the same calculation in matrix form, for the <a href="#xor">XOR problem</a>, which a single perceptron cannot solve. The network has two inputs, a hidden layer with four <span class="math">\tanh</span> units, a sigmoid output and the cross-entropy loss. The notation is the same as in the core material. Each row of <code>X</code> is one example, and a weight matrix has one row for each unit of its layer. Thus, <code>W1</code> has the shape 4 × 2, as the 40 × 784 matrix of the digit network. A layer calculates <span class="math">Z = X W^\top + b</span>.

== b255f91d
Look carefully at the line <code>G2 = (P - Y) / len(X)</code>. When the output is a sigmoid and the loss is cross-entropy, the derivative of the loss with respect to the logit of the output is only <span class="math">p - y</span>: the prediction minus the target. This is the error-times-input form from the <a href="#perceptron-update">perceptron rule</a>. Each layer then needs the two products from the <a href="#cost-dense">extra section below</a>. <code>G2 @ W2</code> sends the error back to the hidden layer, and <code>G1.T @ X</code> gives the weight gradient. A framework such as PyTorch calculates the same products for you with automatic differentiation.

== 76152390
The <a href="#xor">XOR activity</a> set two hidden units by hand: "at least one input is 1" and "both inputs are 1". Gradient descent found a different representation. With seed 1, the printed matrix <code>H</code> shows it. The second hidden unit is near +1 only for the input (1, 0), and the fourth only for (0, 1). For the other inputs, both units are negative. The output weights, <code>params[2]</code>, are largest for these two units (about 7 each). Thus, the network calculates XOR as "<span class="math">x_1</span> and not <span class="math">x_2</span>, or <span class="math">x_2</span> and not <span class="math">x_1</span>". The other two units are large and positive for each input that contains a 1, and they are less important. Many hidden representations solve the same task. Training finds one of them, and it is not always the one that a person would design.

== d5fc58f1
Do two experiments with the code above. First, use only two hidden units, the size of the solution that we set by hand. In the last lines, change <code>(4, 2)</code>, <code>np.zeros(4)</code> and <code>(1, 4)</code> to <code>(2, 2)</code>, <code>np.zeros(2)</code> and <code>(1, 2)</code>. Two units can represent XOR. But in our runs, gradient descent solved it from only 52 of 100 random start values. Almost all other runs stopped with a prediction of about 0.5 for two of the four inputs (seed 0 is one of them). With three units, 84 of 100 runs solved XOR; with four, 98; with eight, all 100. The extra units are not necessary to represent the function, but they make it much easier to find. Second, give each weight the start value 0.5, not a random number. Now all hidden units calculate the same value and get the same gradient. Thus, they stay the same at all times. The network then works as if it has only one hidden unit, and it cannot solve XOR. Random start values break this symmetry, as <a href="#training-loop">Putting the training loop together</a> explains.

== 6ca8e0f3
A network with one hidden layer can approximate any continuous function on a bounded region as accurately as you want, if it has sufficient hidden units. Cybenko (1989) proved this for sigmoids. Leshno, Lin, Pinkus and Schocken (1993) proved it for each continuous activation that is not a polynomial. People often say that this theorem means "neural networks can learn anything". This is not correct. The theorem does not tell you <b>how many</b> units are necessary (possibly an extremely large number). It does not tell you if <b>gradient descent</b> will find the weights. It also does not tell you how well the result <b>generalizes</b> from a finite training set. In practice, depth is part of the answer: a deep network can represent some functions with few units, but a shallow network needs exponentially many units for them.

== 1597246b
The core material describes what each method calculates. This section asks what the calculation costs. How do time and memory increase with the size of the data and of the model? Why can the same arithmetic run ten or a hundred times faster when we arrange it differently? We count <b>multiply–accumulate operations</b> (MACs) and bytes. One MAC is two floating-point operations (FLOPs). Notation: <span class="math">N</span> training examples, mini-batches of <span class="math">B</span> examples, <span class="math">P</span> parameters and <span class="math">E</span> epochs.

== 16a5f11c
A dense layer with <span class="math">n</span> inputs and <span class="math">m</span> outputs has <span class="math">mn + m</span> parameters. For one example, it needs <span class="math">mn</span> MACs. For a mini-batch, the inputs are the rows of a matrix <span class="math">X</span>, and the full batch is one matrix product:

== 6c6993cc
When we add all layers, a forward pass costs about one MAC for each weight and each example, or <span class="math">2P</span> FLOPs. The backward pass costs about two times as much, because each layer calculates two products of the same size. These are the gradient for its input, <span class="math">G W</span>, and the gradient for its weights, <span class="math">G^\top X</span>. Here <span class="math">G</span> contains the derivatives of the loss with respect to <span class="math">Z</span>. Thus, one training step costs about <span class="math">6P</span> FLOPs for each example, and the full training costs

== 789d1ebf
The batch size is not in the formula. It changes the number of updates (<span class="math">N/B</span> in each epoch) and how efficiently the hardware works. It does not change the quantity of arithmetic. The digit network of the core material has <span class="math">P = 31{,}810</span>. Thus, one training step costs about <span class="math">6P \approx 191{,}000</span> FLOPs for each image. The 8 epochs over the 6,400 training images of the exercise need about <span class="math">9.8 \cdot 10^{9}</span> FLOPs. One modern CPU core with vector instructions can do approximately <span class="math">10^{11}</span> FLOPs each second. An example is 3 GHz × 2 fused multiply–add units × 8 single-precision lanes × 2 FLOPs. Thus, the arithmetic alone takes about 0.1 seconds. Real code takes more time: small matrices, memory traffic and the Python interpreter add overhead. Performance engineering decreases this difference.

== 6a12dab0
<b>Memory.</b> Training keeps four types of numbers. These are the <span class="math">P</span> parameters, their <span class="math">P</span> gradients, the state of the optimizer and the <b>activations</b> of each layer. The optimizer state is zero for plain SGD, <span class="math">P</span> for momentum and <span class="math">2P</span> for Adam. The backward pass needs the activations: <span class="math">B \sum_\ell n_\ell</span> values for the layer widths <span class="math">n_\ell</span>, with the input. Prediction needs only the parameters and the activations of the current layer. In the digit network, the parameters use 127 KB as 32-bit floats. This is small enough to stay in the cache of a CPU core. The activations of a batch of 200 images use 0.67 MB.

== 415fce31
<b>Performance: select the number format.</b> The 70,000 MNIST images use 439 MB as 64-bit floats, which <code>fetch_openml</code> gives. As 32-bit floats they use 220 MB, and as bytes 55 MB. Thus, the exercise changes them with <code>astype("float32")</code>. This halves the memory traffic, and each vector instruction holds two times as many numbers (8, not 4, in a 256-bit AVX2 register). Neural networks rarely need 64-bit precision. GPUs go further: they train with 16-bit formats (see the checklist below).

== 392639e9
A processor can calculate only as fast as it gets the data. The <b>arithmetic intensity</b> of a calculation is the number of FLOPs for each byte that it moves to or from memory. A matrix–vector product, with one example at a time, uses each weight one time: 2 FLOPs for each weight. With 16-bit weights, this is about 1 FLOP for each byte. A mini-batch of <span class="math">B</span> examples uses each weight <span class="math">B</span> times, so the intensity increases with <span class="math">B</span>. The <b>roofline model</b> changes this into a speed limit:

== 85dac47b
On the example device of the figure, a layer of width 4096 gets 1% of the peak at batch size 1. At batch size 16 it gets 16%, and at 128 the full peak. Below the ridge point (here 100 FLOP for each byte), a calculation is <b>memory-bound</b>. Then faster arithmetic does not help. Only less data movement helps. Above the ridge point, the calculation is <b>compute-bound</b>. Matrix libraries (BLAS on CPUs, cuBLAS on NVIDIA GPUs) get near the peak. They divide the matrices into tiles that stay in the registers and caches while the library uses them again. You can see the effect on a laptop:

== a311b84e
The two versions do the same <span class="math">8.6 \cdot 10^{9}</span> FLOPs. The loop reads the 64 MiB weight matrix from memory 256 times, 16 GiB in total. The single product reads it about one time, and it uses each tile again from the cache. On the 4-core machine that we used to test this page, the single product was 7 to 10 times faster. On a GPU, the difference is larger. Mini-batches are useful for statistical reasons, as the core material explains. They also make neural networks fast on real hardware.

== e7129f8a
A perceptron prediction costs <span class="math">O(d)</span> for <span class="math">d</span> inputs. Thus, one epoch costs <span class="math">O(Nd)</span> time, and <span class="math">O(d)</span> memory in addition to the data. How many epochs are necessary? The convergence theorem (Novikoff, 1962) gives the answer from the geometry of the data. Use the labels −1 and +1, and a constant input 1 for the bias. Let each input have <span class="math">\lVert x \rVert \le R</span>. Let a unit vector <span class="math">u</span> separate the classes with the margin <span class="math">\gamma</span>: <span class="math">y\, u \cdot x \ge \gamma</span> for each example. Then the perceptron makes a maximum of

== d421e47f
Each epoch before convergence has one or more mistakes. Thus, training takes a maximum of <span class="math">(R/\gamma)^2 + 1</span> epochs and <span class="math">O\bigl(Nd\,(R/\gamma)^2\bigr)</span> time. When the classes are separable but almost touch, the margin is small, and training can need many epochs. For XOR, there is no margin, and the bound gives no information.

== 0746c528
<b>Performance: vectorize the independent work.</b> Each perceptron update changes the weights that the next example uses. Thus, the loop over the examples must go in sequence. Only the dot product in each step can use vector instructions. A mini-batch gradient step is different: all <span class="math">B</span> examples use the same weights, so one matrix product gives all their gradients. When you must use a loop in sequence, run it as compiled code (C++, Numba or <code>jax.lax.scan</code>), not in the Python interpreter. In the interpreter, each iteration costs much more than its arithmetic.

It calculates <span class="math">H_\text{out} W_\text{out} C_\text{out}</span> outputs, and each output needs <span class="math">k^2 C_\text{in}</span> MACs:

== 245b1dbb
The 16 RGB filters of size 3 × 3 in the core material have 448 parameters. On a 32 × 32 image with padding 1, they do <span class="math">32 \cdot 32 \cdot 16 \cdot 27 = 442{,}368</span> MACs. This is about 1,000 for each parameter. A dense layer uses each weight only one time for each example. This high arithmetic intensity is one reason why CNNs run well on GPUs. But the cost moves to the memory. One 224 × 224 feature map with 64 channels has 3.2 million values, 12.8 MB as 32-bit floats. == 81f74e57
<b>Performance: one operation, different algorithms.</b> Libraries implement a convolution in different ways. <i>im2col</i> copies each patch into a column of a matrix and then uses a fast matrix product. But the copied input needs about <span class="math">k^2</span> times more memory (Chellapilla et al., 2006). Winograd's minimal filtering calculates a 2 × 2 block of outputs of a 3 × 3 filter with 16 multiplications, not 36: 2.25 times fewer (Lavin and Gray, 2016). Methods with the FFT are good for large filters. On NVIDIA GPUs, cuDNN selects one of these algorithms for each layer shape. In PyTorch, <code>torch.backends.cudnn.benchmark = True</code> lets cuDNN measure the time of each algorithm one time and keep the fastest. The memory layout is also important. "Channels last" (NHWC) keeps the channels of one pixel next to each other. This is good for vector instructions and tensor cores.

== 1cff97da
An embedding lookup copies one row of the table: <span class="math">O(d)</span> for each token. A one-hot vector times the table gives the same result, but it costs <span class="math">O(Vd)</span>. The table can be the largest part of a model, for example in recommender systems. The backward pass changes only the rows of the tokens in the batch. To find the nearest neighbours of one vector among <span class="math">V</span> vectors costs <span class="math">O(Vd)</span>. Normalize the table one time. Then one matrix–vector product gives all cosine similarities. For millions of vectors, approximate nearest-neighbour indexes such as HNSW (Malkov and Yashunin, 2020) are much faster, but a little less accurate. Vector databases use these indexes.

== 44df6543
A recurrent step <span class="math">h_t = \tanh(W_x x_t + W_h h_{t-1} + b)</span> costs <span class="math">d_h (d_x + d_h)</span> MACs. Thus, a sequence of length <span class="math">T</span> costs <span class="math">O\bigl(T d_h (d_x + d_h)\bigr)</span> time. Training keeps all <span class="math">T</span> hidden states: <span class="math">O(T d_h)</span> memory for each sequence. <b>Performance:</b> the steps cannot run in parallel, because step <span class="math">t</span> needs <span class="math">h_{t-1}</span>. Only the sequences of a batch can run in parallel. Attention in Week 5 removes this dependency and processes all positions at the same time. But it must compare each pair of positions: <span class="math">O(T^2)</span> parallel work, not <span class="math">T</span> steps in sequence.

== 7d60e116
<b>Measure first.</b> Profile before you optimize: <code>cProfile</code> or py-spy for Python, <code>torch.profiler</code> for PyTorch, Nsight Systems for NVIDIA GPUs. Frequently, the slow part is not where you expect it.

== ab2779c9
<b>Find the limit.</b> Compare the FLOP/s that you get with the peak. Also compare the bytes per second that you get with the memory bandwidth. A memory-bound calculation needs less data movement, not faster arithmetic.

== fef15ffe
<b>Use smaller number formats.</b> On CPUs, use 32-bit floats, not 64-bit floats. On GPUs, mixed precision calculates with 16-bit formats on tensor cores and adds the results in 32 bits (Micikevicius et al., 2018). bfloat16 has the same exponent range as 32-bit floats. float16 needs loss scaling, so that small gradients do not become zero.

== 752f145f
<b>Use good shapes.</b> Tensor cores work best when the matrix dimensions are multiples of 8 for 16-bit numbers. Larger multiples frequently help more.

== 6d8c138c
<b>Keep the device busy.</b> While the current batch trains, load and preprocess the next batches in background workers. A GPU that waits for data shows low utilization.

== 4a72769a
<b>Use more computation to save memory.</b> Gradient checkpointing keeps the activations of only some layers. It calculates the other activations again during the backward pass. It keeps about <span class="math">\sqrt{L}</span> layers, not <span class="math">L</span>, and it needs about one more forward pass (Chen et al., 2016).

== 797aec02
<b>Fuse small operations.</b> A chain of element-wise operations is memory-bound when each operation reads and writes a full tensor. Compilers such as <code>torch.compile</code> and XLA fuse them into one pass.
