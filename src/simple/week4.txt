== 69dac595
A neural network is a model. The model learns its parameters from examples. We make a neural network from a sequence of simple transformations. Thus, the network can learn useful intermediate representations. A person does not have to design each feature by hand.

== 3f625e9f
A perceptron receives an input vector <i>x</i>. It multiplies each input by a learned weight. Then it adds a bias and applies a threshold. In short, it makes its prediction from <span class="math">w^\top x + b</span>. During training, the weights change when the prediction is wrong. A perceptron can learn a linear decision boundary (a straight line or a flat plane). But it cannot represent every classification problem.

== f17204ba
Example: the inputs are <span class="math">(1, 2)</span>, the weights are <span class="math">(0.7, -0.2)</span> and the bias is 0.1. The weighted sum is <span class="math">0.7 \times 1 - 0.2 \times 2 + 0.1 = 0.4</span>. The result is positive, so a step activation gives class 1. The weights set the position and the direction of the separating line. The bias moves the line, but it does not change the direction of the line.

== 9661313b
When the classes are linearly separable, the perceptron learning rule converges (it stops at a solution). The perceptron cannot solve XOR. No single straight line can put the two blue points on one side and the two orange points on the other side. This is a limit of what the model can represent. More training time does not solve it.

== 4f466150
The perceptron predicts +1 when <span class="math">w \cdot x + b &gt; 0</span>. Otherwise, it predicts −1. It goes through the examples in a fixed sequence. After each mistake, it changes the weights with <span class="math">w \leftarrow w + y\,x</span> and the bias with <span class="math">b \leftarrow b + y</span>. On linearly separable data, the mistakes stop after a finite number of updates. On XOR, the mistakes never stop.

== df1ab4c9
A multilayer perceptron has an input layer, one or more hidden layers and an output layer. The neurons are in these layers. Each layer transforms the representation from the layer before it. The width of a layer is its number of units: more units can represent more patterns. The depth is the number of layers: with more layers, the model can make complex transformations from simple ones.

== d3cdcf40
Nonlinear activation functions are necessary. Without them, many layers on top of each other still give only a linear model. Many networks use ReLU, because it is simple and it works well in many cases. Sigmoid changes values to the range from zero to one. Tanh changes values to the range from minus one to one. The activation function has an effect on how easily the network trains. It also has an effect on the types of decision boundaries that the network can learn.

== 78a25808
Backpropagation multiplies by the derivative of the activation function. The derivative of the step function is zero at all points except 0, where it has no value. Thus, it gives no gradient for learning. The derivative of the sigmoid is <span class="math">\sigma'(z) = \sigma(z)\bigl(1 - \sigma(z)\bigr)</span>. Its maximum value is 0.25. The derivative of tanh is <span class="math">1 - \tanh^2 z</span>. Its maximum value is 1. The derivative of ReLU is 0 for negative inputs and 1 for positive inputs.

== 2210e569
Training starts with a loss function. The loss function measures the difference between the predictions and the target values. Backpropagation uses the chain rule. It calculates how much each parameter added to the loss. Then an optimizer uses these gradients to change the parameters. For this course, the important idea is that each part has one task:
the forward pass makes a prediction, the loss measures the error of the prediction, backpropagation gives the gradients, and the optimizer changes the model.

== 936adb67
Good performance on the training data is not sufficient. We use separate validation data and test data. With them, we find if the network generalizes to new examples (works well on data that it did not see). Too much model capacity or too much training can cause overfitting. Regularization, a correct model size and early stopping can decrease this problem.

== 6b6980c8
An embedding shows a discrete item (for example, a word) as a vector of learned numbers. Items that occur in similar contexts usually get similar vectors. Thus, an embedding replaces an arbitrary identifier with a representation where distance and direction can show useful relations. We use the same idea for text tokens, images, users, products and many other types of data.

== 1c4829da
Neural networks learn representations in layers. They combine linear transformations and nonlinear activation functions. Training changes their parameters with gradients. Embeddings use representation learning for discrete items, for example words. They also prepare you for attention and Transformers in Week 5.

== 6de0beef
With <code>solver="sgd"</code>, each of the 8 iterations (<code>max_iter</code>) is an <b>epoch</b>. An epoch is one pass over the full training set. The code uses mini-batches of 200 images (the default <code>batch_size</code>). For each mini-batch, the network does the steps from the lecture: a forward pass, a loss calculation, a backward pass and a weight update with gradient descent. There are 60,000 training images, so there are 300 weight updates in each epoch. This is more than the perceptron from the start of this week, because the training rule is different. <code>MLPClassifier</code> makes a differentiable loss (cross-entropy) as small as possible. It uses backpropagation to calculate how each weight must change, also the weights of the hidden layer. The perceptron learning rule can train only one layer of weights.

== 960e1b0c
<code>MLPClassifier</code> and Keras do the training loop for you, so you do not see it. Here is the full loop, for the XOR problem, which a single perceptron cannot solve. The network has two inputs, a hidden layer with four <span class="math">\tanh</span> units, a sigmoid output and the cross-entropy loss. The backward pass applies the chain rule to one layer after the other, from the loss back to the first weights.

== ad258e93
Look carefully at the line <code>d_out = (p - y) / len(X)</code>. When the output is a sigmoid and the loss is cross-entropy, the derivative of the loss with respect to the logit of the output is only <span class="math">p - y</span>: the prediction minus the target. All other lines are matrix calculus. A framework such as PyTorch does this matrix calculus for you with automatic differentiation.

== dac84dc2
Do two experiments with the code above. First, change the seed to 0. Now the network stops on a plateau (a flat area of the loss), and for two of the four inputs it predicts about 0.5. (In our runs, 19 of 20 seeds solved XOR.) Gradient descent finds <i>a</i> low point, but not always the best low point. Second, give each weight the start value 0.5, not a random number. Now all hidden units calculate the same value and get the same gradient. Thus, they stay the same at all times. The network then works as if it has only one hidden unit, and it cannot solve XOR. A random start breaks this symmetry. The scale of the random start values is also important (Xavier or He initialization). A good scale prevents that the signals in deep networks become too small or too large.

== 6ca8e0f3
A network with one hidden layer can approximate any continuous function on a bounded region as accurately as you want, if it has sufficient hidden units. Cybenko (1989) proved this for sigmoids. Leshno, Lin, Pinkus and Schocken (1993) proved it for each continuous activation that is not a polynomial. People often say that this theorem means "neural networks can learn anything". This is not correct. The theorem does not tell you <b>how many</b> units are necessary (possibly an extremely large number). It does not tell you if <b>gradient descent</b> will find the weights. It also does not tell you how well the result <b>generalizes</b> from a finite training set. In practice, depth is part of the answer: a deep network can represent some functions with few units, but a shallow network needs exponentially many units for them.
