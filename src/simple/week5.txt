== b188cf20
Week 4 showed embeddings: vector representations that a model learns. A static embedding cannot change its meaning when the sequence around it changes. Attention solves this problem: each position can select and combine information from other positions. This section explains this mechanism. It also shows why it became the base of the Transformer.

== ca58998a
Look at the word <i>bank</i> in “the bank approved the loan” and in “we sat on the river bank.” A static lookup gives the same initial vector in the two sentences. Attention makes a contextual representation: it combines information from the tokens around the word, and it gives each token a different strength.

== abcfffed
First, remember the situation before 2017. (In 2017, the first paper about the Transformer architecture was published.) Before 2017, the usual method for sequences was recurrent neural networks (RNNs). But this method has some limits that people know well:

== 906e85b7
<b>Memory bottleneck:</b> an RNN keeps all information about the sequence in a hidden state. The RNN updates this state at each step. Sometimes the model must "remember" something that occurred hundreds of steps before. Then the hidden state must keep this information, and new data must not replace it. Thus, the hidden state must be very large, or some information is always lost.

== a814cd45
<b>Sequential processing:</b> it is difficult to train recurrent networks in parallel. To calculate the hidden state of the RNN layer at step <span class="math">i + 1</span>, you must first calculate the state for step <span class="math">i</span>. Thus, a batch of sequences with a length of 1000 needs 1000 operations, one after the other. This makes training slow. It is also not efficient on GPUs, because GPUs are optimized for parallel calculations.

== c6a0abbe
Because of these problems, it is difficult to use RNNs for very long sequences. Even when the training is complete, the model always loses information from the start of the text, because of its design. We want a method to "read" a sequence so that, at each moment, the model can go directly to each earlier point. It must do this in one step and with no loss of information.

== c5390025
The self-attention mechanism, which is the core of Transformers, gives exactly this. Later, we will see that this mechanism is effective for natural language processing. Later, people also used the same idea in many other domains.

== aa20d468
The left side of the diagram shows the structure of the encoder. It applies <span class="math">N</span> blocks to the input sequence, one after the other:

== ccc22d96
Each block gives a sequence of the same length as its output. It has two important layers: <b>multi-head attention</b> and <b>feed-forward</b>. After each of these layers, the input is added to the output again. (This is a standard method, and its name is <i>residual connection</i>.) Then the activations go through a <b>layer normalization</b> layer. In the diagram, the label of this part is "Add &amp; Norm".

== b4fa20fc
The decoder has a similar structure. But each of its <span class="math">N</span> blocks has two <b>multi-head attention</b> layers. One of these layers uses the outputs of the encoder.

== c04a1006
Now we look more closely at each important component of this mechanism.

== 8d3a8f81
The first part of the Transformer block is the <b>self-attention layer</b>. Standard attention mechanisms are different. The output of self-attention is new representations for the elements of the same input sequence. In it, each element interacts directly with all other elements.

== 3ac3cb0a
More precisely, attention for a sequence uses three trainable matrices: <span class="math">W_Q, W_K, W_V</span>. We multiply the representation <span class="math">x_i</span> of each input element by these matrices. This gives the row vectors <span class="math">q_i = x_i W_Q,\ k_i = x_i W_K,\ v_i = x_i W_V</span> (<span class="math">i</span> is the index of the element). The names of these vectors are <b>query, key and value</b>, in this order.

== a464ee83
Approximately, their roles are these:

== 01144268
<span class="math">k_i</span> — the keys of the values in the database. The lookup uses them.

== 610a489c
<span class="math">v_i</span> — the values that are really in the database.

== 701d3423
Here, <span class="math">Q, K, V</span> are the matrices of queries, keys and values. Their rows are the vectors <span class="math">q_i, k_i, v_i</span>. Softmax is applied to each row.

== aa267ea8
No part of this formula depends on the order of the tokens. If you put the input tokens in a random order, the outputs change their order in the same way. Thus, self-attention alone does not see the word order. Transformers solve this: they add <b>positional information</b> to the token representations. The first paper added fixed sinusoidal <b>positional encodings</b> to the input embeddings. BERT and GPT learn an embedding for each position. Many new models turn (rotate) the queries and keys by an angle that depends on their positions (rotary position embeddings, RoPE).

== 70d35207
The fixed encodings of the first Transformer, here with <span class="math">d = d_{\text{model}} = 64</span>: <span class="math">\mathrm{PE}(pos, 2i) = \sin\bigl(pos / 10000^{2i/d}\bigr)</span> and <span class="math">\mathrm{PE}(pos, 2i+1) = \cos\bigl(pos / 10000^{2i/d}\bigr)</span>. The wavelengths increase geometrically, from 2π in the first dimensions to approximately 10000·2π in the last dimensions. Thus, each position gets its own pattern. This pattern is added to the token embedding. Put the pointer on a cell, or click a column to show a plot of that dimension.

== 1edfdaf1
We said before that one of the attention layers in the decoder is a <b>cross-attention layer</b>. In it, the queries come from the output sequence, and the keys and values come from the input (that is, from the outputs of the encoder).

== 8a8642ee
There is one more important property of attention in the decoder. In the form above, each token can see the full sequence. This is not correct for the decoder. During generation, we make tokens one step at a time. If the model sees future tokens during training, information leaks, and the model performs badly.

== 410bf574
To prevent this problem, the decoder applies an <b>autoregressive mask</b> to attention. It does this during training, and also when it processes a prompt during generation. The mask sets the attention scores for future tokens to <span class="math">-\infty</span> before the softmax operation. Thus, their weights are zero after the softmax. The image below shows that this mask has a lower triangular shape.

== f4785133
The same word gets the same query, key and value vectors in the two sentences, so it starts from the same static embedding. But the attention weights <span class="math">\softmax(QK^\top / \sqrt{d_k})</span>, and thus the output, depend on the other words. With the causal mask, the scores for later tokens are set to −∞ before the softmax. Thus, the weight matrix becomes lower triangular. The table follows one query row step by step, from the dot products to the weighted sum of the values. The vectors are small toy examples that we selected by hand to show the mechanism. They do not come from a trained model, and they contain no positional information. For this reason, the two copies of “the” get the same rows in the bidirectional matrix. This is the order blindness that positional encodings remove.

== 7e963cb6
One set of matrices <b>Q</b>, <b>K</b> and <b>V</b> can find only one type of dependency between tokens. Also, these matrices get only a limited range of information from the input representations. To solve this problem, the authors of the Transformer architecture added the concept of <b>multi-head attention</b>.

== 34eabb1a
It does not use one attention mechanism. It applies many parallel attention layers ("heads") with different learned weights at the same time. Then it joins (concatenates) the results of all heads and sends them through a linear transformation. Thus, the model can attend to different parts of the input sequence and find many relations in parallel.

== 507bdf2a
When attention processes the full sequence, there is no hidden state that updates recurrently. Each token can directly "read" the part of the sequence that is most useful for the prediction. Because there is no recurrence, we can apply the layer to the full sequence at the same time. This uses matrix multiplications, which run efficiently in parallel.

== 08c9013d
But we must think about the costs in memory and time. Each element in the sequence interacts with all other elements. Thus, it is easy to show that the computational complexity of self-attention is <span class="math">O(n^2)</span> in the sequence length. Also, simple implementations that make a full attention matrix need <span class="math">O(n^2)</span> memory.

== f420022d
Much research tries to make attention more efficient. Some of it is engineering, and some of it changes the architecture. Some methods make the run time of self-attention linear. Others make the use of memory much more efficient, because they use the memory hierarchy of the GPU.

== 21cd2d28
Attention is one component of a Transformer block. This section shows how attention, feed-forward layers, residual connections and normalization make full encoder and decoder architectures. Then it compares representation learning in the style of BERT with autoregressive generation in the style of GPT. It also looks at applications that are not text.

== 1ad7094e
The same general pipeline can have different objectives. An encoder can make contextual representations for classification or retrieval. An autoregressive decoder uses a causal mask, and it predicts the next token again and again. Encoder-decoder models change one sequence into a different sequence, for example in translation. The details below explain the operations that each block repeats.

== c5a38255
The second component of the Transformer block is the <strong>feed-forward network (FFN)</strong>. It has two fully connected layers, which are applied separately to each element of the input sequence. In modern architectures, the intermediate representation (that is, the output of the first layer) is often much larger. Usually, it is four times the output size of the block.

== d538e5db
Now some words about <strong>layer normalization</strong>. Some research <a href="https://aclanthology.org/2020.emnlp-main.463/" target="_blank" rel="noopener">papers</a> show that its position in the residual connection is very important. The standard Transformer architecture uses the <strong>PostLN</strong> form. In this form, normalization is applied <em>after</em> the residual connection.

== 02eda039
But this method can be quite unstable when you train deep models with many layers. An alternative method is <strong>PreLN</strong> (on the right in the image below). It applies normalization to the <em>input</em> of each sub-layer (attention or FFN), in the residual branch: <span class="math">x + F\bigl(\operatorname{LN}(x)\bigr)</span>. Thus, the residual connection itself does not go through the normalization.

== 3a2c6979
Transformer-based models are interesting because this architecture solves almost all modern NLP tasks. Two well-known families of models made <strong>self-attention</strong> popular very quickly: <strong>BERT</strong> and <strong>GPT</strong>. We can think of them as the <em>encoder</em> and the <em>decoder</em> of the Transformer. Later, they became independent architectures.

== 33453a30
In time order, <a href="https://openai.com/research/language-unsupervised" target="_blank" rel="noopener"><strong>GPT</strong></a> (Generative Pretrained Transformer) came first. It is a standard language model. It is a stack of Transformer <strong>decoder</strong> layers.

== 017a6813
The training objective is only <strong>next-token prediction</strong>. Thus, at each step, it does multi-class classification over a vocabulary. An important property of GPT is the <em>lower-triangular attention mask</em>. Without it, earlier tokens can see future tokens, and data leaks.

== 19507888
You can use the trained model for <strong>text generation</strong> and for tasks that use text generation. <strong>ChatGPT</strong> also has the same architecture as the base GPT model. The difference is the additional training: fine-tuning on instructions and example dialogues, and reinforcement learning from human feedback (RLHF). This training changes the behaviour of the model very much.

== 928fbce5
The name <strong>Bidirectional Encoder Representations from Transformers (BERT)</strong> shows the difference from GPT: BERT uses <strong>bidirectional attention</strong>. This means that, when BERT processes the input sequence, all tokens can use information from all other tokens.

== 582d6836
Thus, BERT is good for tasks where the prediction must use the full input and where no text is generated. Examples are <strong>sentence classification</strong> and <strong>document similarity search</strong>. But BERT does not generate new text from nothing.

== 0cac7bf8
BERT has two important training objectives:

== 8967c9c4
<strong>Masked Language Modeling (MLM):</strong> predict words that are randomly hidden (masked), from the words around them (see the image below).

== 3d3c2dc5
<strong>Next Sentence Prediction (NSP):</strong> decide whether one text fragment logically comes after another text fragment.

== 9edaf385
If you only implement a <strong>Transformer</strong> neural network and train it with the usual hyperparameters of other architectures, it will very probably fail. The optimization of these models often needs changes. If you ignore these details, the quality can become much worse, or the training can become unstable.

== c132fda2
One very important factor is the <strong>batch size</strong>. Almost all modern Transformer models train on very large batches. In the largest language models, a batch can contain <strong>millions of tokens</strong>. No modern GPU can process so large a batch in one step. Thus, people usually use methods such as <a href="https://sebastianraschka.com/blog/2023/llm-grad-accumulation.html#what-is-gradient-accumulation" target="_blank" rel="noopener"> gradient accumulation</a>: they add up the gradients of many micro-batches, and then they do one update.

== adffc311
Smith et al. (2018) also proposed to <a href="https://openreview.net/forum?id=B1Yy1BxCZ" target="_blank" rel="noopener"> increase the batch size dynamically</a> during training. Large language models often train with a batch size that increases during the first part of the training. The reason: at the start of training, it is very important to do gradient descent steps frequently. Later, it is more important that the estimate of the gradient is accurate.

== d4f59b38
Another very important factor is the selection of the <strong>optimizer</strong> and of the <strong>learning rate schedule</strong>. If you train a Transformer with standard <strong>SGD</strong>, it will very probably not work. The first Transformer paper used the <strong>Adam</strong> optimizer. Adam is still the standard selection today, usually in its <strong>AdamW</strong> variant, which uses decoupled weight decay.

== 95dca1b2
But with large batch sizes, Adam sometimes has problems. Thus, researchers use alternatives, for example <a href="https://arxiv.org/abs/1904.00962" target="_blank" rel="noopener">LAMB</a>. LAMB normalizes the weight updates for each layer, so that the training is stable.

== 2ccd5833
This family of architectures was very successful in many tasks with text. Thus, researchers in other domains also saw it. One of the most important new areas for Transformer-based models is <strong>computer vision</strong>.

== ae8445ea
For example, the <a href="https://arxiv.org/abs/2010.11929" target="_blank" rel="noopener">ViT (Vision Transformer)</a> architecture got record accuracy in classification on image datasets at one time. It divides images into many <strong>patches</strong> (square segments) and uses the self-attention mechanism on them.

== b3e52078
The authors of the paper explain that they had the idea to use the Transformer architecture in vision after they saw the success of these models in <strong>NLP</strong>. A general method such as <strong>self-attention</strong> lets the architecture work without explicitly encoded properties of the task (the name of these properties is <em>inductive bias</em>). But this is true only when there is sufficient training time, a large number of parameters and a very large dataset.

== 23d8f618
Transformers are also the base of the generative component of the first <strong>DALL-E</strong> (2021). This model started much research in text-to-image generation. As a concept, it is quite simple: we can think of it as an autoregressive <strong>"language model"</strong> that makes an image one <strong>"visual token"</strong> at a time. (The models after it, DALL-E 2 and 3, are diffusion models, like Stable Diffusion. Their denoising networks also use attention.)

== e3c45465
Transformers are also used in <strong>reinforcement learning</strong>. An important example is the paper <a href="https://arxiv.org/abs/2106.01345" target="_blank" rel="noopener">Decision Transformer</a>. It proposes to make an agent with autoregressive modelling and this architecture.

== 824899a9
The authors showed that the method for text generation also works to predict actions in a dynamic environment. The image below shows the method. The model gets groups of three items, one group after the other: encoded returns-to-go (the total reward that the agent can still collect from that step), states and actions. At each step, it gives the next action. At test time, the first return-to-go is set to the return that we want the agent to get.

== f16eb091
A task-specific model is trained for one defined problem with inputs and outputs. A <b>foundation model</b> is pretrained on wide data at a sufficient scale, so that it can support many downstream tasks. The <a href="https://arxiv.org/abs/2108.07258" target="_blank" rel="noopener">Stanford report on foundation models</a> developed the term systematically. You can adapt the same base model for classification, retrieval, generation, question answering or interaction. This reuse changes the unit of AI development. More and more, people select, prompt, adapt and evaluate pretrained models. They do not train each system from the start.

== 8501f54e
Scale alone does not define a foundation model. The main property is wide transfer. Pretraining learns representations and regular patterns of behaviour from a general objective, for example to predict missing tokens or the next token. Then, in downstream use, prompts, demonstrations, retrieved context or more training specify the task.

== 54f59184
Multimodal models connect representations from text, images, audio, video, actions or sensor data. Some of them map different modalities into one shared embedding space. This makes retrieval across modalities possible. Others accept more than one modality as context and make text, images, audio or actions. For example, a vision-language model can answer questions about an image, because its visual features are aligned with language representations.

== cc2c6140

It is not sufficient to examine only the quality of the language.

== 69ad9d7d
Up to now, you studied machine learning models that mainly predict some properties of objects, for example class labels or regression targets. The name for these tasks is <strong>discriminative modeling</strong>.

== 008b86b5
But there are also inverse problems. In them, we must make an object from some properties, or we must estimate the probability distribution of objects. The name for this is <strong>generative modeling</strong>. In this section, we look at its most important aspects.

== 7fa30c0d
It is much more difficult to train generative models than discriminative models. Discriminative models work with much simpler distributions. For example, it is much easier to predict the probability that a specific digit is in an image than to make an image with the wanted digit. But generative models were very successful in the last years. They can make images that are almost the same as real photographs.

== 3966432e
Generative models help to solve many different tasks. We look at them below. The most basic task is to approximate the data distribution and to make new data.

== 682385ce
Think of a dataset of images of handwritten digits. We assume that this dataset is a sample from a larger population (that is, the full set of possible images). Our goal is to make a model of the distribution of this population.

== 096f9328
There are two methods to do this:

== 84f6da3c
<strong>Explicit modeling:</strong> here, we make and estimate the probability density function <span class="math">p(x)</span>. From this distribution, we can sample new objects. Autoregressive models and normalizing flows can calculate <span class="math">p(x)</span> exactly. Variational autoencoders and diffusion models are trained on a lower bound of <span class="math">\log p(x)</span>, so their density is only approximate. Examples of these models are:

== d4e7bfb9
Autoregressive models (for example <a href="https://arxiv.org/pdf/1701.05517" target="_blank" rel="noopener">PixelCNN++</a> and <a href="https://arxiv.org/pdf/1906.02634" target="_blank" rel="noopener">Video Transformer</a>)

== ba1eac3b
<strong>Implicit modeling:</strong> here, we do not estimate the probability density function directly. But we can still sample new objects from the learned distribution. In our example of handwritten digits, we can make similar images. An important example of these models is <strong>Generative Adversarial Networks (GANs)</strong>.

== 755875b2
Now we give a formal description of the difference between discriminative and generative tasks. In discriminative modeling, we have an object <span class="math">x</span> and a label <span class="math">y</span>. We usually want to estimate the conditional probability <span class="math">p(y \mid x)</span>.

== 31449808
In generative modeling, the goal is the opposite: to find the probability <span class="math">p(x)</span> or <span class="math">p(x \mid y)</span>. Here, <span class="math">y</span> can be a class label or a different object. For example, if we want to make images from a text description, the images are <span class="math">x</span> and the text is <span class="math">y</span>.

== cd0479f7
Most generative models let us sample new objects. Usually, when we train a generative model, we get a <strong>generator</strong>: a function that gives an object as output.

== d36aaae9
In models such as <strong>Generative Adversarial Networks (GANs)</strong>, <strong>diffusion models</strong> and <strong>variational autoencoders (VAEs)</strong>, the input of the generator is a vector of random values from a simple probability distribution (for example normal or uniform). We can write this as:

== b2ce4b7b
Here, <span class="math">x</span> is the generated object, <span class="math">G</span> is the generator function, and <span class="math">z</span> is the vector of random values. The space where <span class="math">z</span> is has the name <strong>latent space</strong>.

== e1a8870d
Usually, we set the distribution of <span class="math">z</span> before the training of the model, and it does not change during the training. Because we know the distribution, we can sample as many different values of <span class="math">z</span> as necessary.

== 329269cf
Look at two vectors <span class="math">z_1</span> and <span class="math">z_2</span> from the latent space and at the objects that the generator makes from them:

== 5ab27a88
<span class="math">z_1</span> and <span class="math">z_2</span> are two points in the latent space. Thus, we can draw a line between them. The points on this line are also in the latent space. If we move along this line and give these intermediate points to the generator, the generated object changes smoothly.

== 4a640db4
In the example above, we moved along a straight line. But in practice, the interpolation can follow a more complex path.

== 4455950c
Changes in the latent space let us make smooth transitions between objects. They also let us <strong>edit generated objects</strong>. For this, we usually must find directions in the latent space that agree with specific properties of the generated objects.

== 4d2a7c35
For example, when a model makes human faces, we can find a direction for <strong>hair color</strong> or for <strong>smiling expressions</strong>. We look at these methods in more detail in the sections about specific models.

== 767fe874
Why do we need to make new data or estimate its density? The simplest example is <strong>data augmentation</strong>. It helps to prevent overfitting, and it improves how well a model generalizes.

== 1dd7946d
Almost all machine learning methods use simple data augmentations, for example random shifts, rotations, scaling, and changes of color and contrast. But <strong>generative models</strong> give a more advanced type of data augmentation. They can make a dataset much larger, or add fully new elements to it.

== 5f2f9ceb
For example, a generative model that does <strong>style transfer</strong> (it puts the style of one image on a different image) can help to train classification models that are more robust. In <a href="https://www.nature.com/articles/s41598-019-52737-x" target="_blank" rel="noopener"> a study by Sandfort et al.</a>, generative neural networks made data augmentation that improved the quality of segmentation in CT scans.

== 107396a3
Also, many <strong>image editing tasks</strong> use generative models. They <strong>increase the resolution of images</strong>. The name of this problem is <em>super-resolution</em>.

Generative Adversarial Networks (GANs) are a large class of generative models. They train together with a second network, which tries to find the difference between generated objects and real objects.

== 889a44b5
In this section, we show the basics of GANs and give an intuitive explanation of how they work. We also look at many techniques and changes that make the first method better in the most successful models.

== c26337cd

== 74decff9
For generative models that can only sample, but cannot estimate density, the simplest and most effective design is this: change one set of random variables into a different set.

== ff608c47
Generative Adversarial Networks (GANs) are implicit generative models. This means that they do not explicitly estimate the probability density of the data. They learn to sample from the data distribution.

== 6fcd11e5
A classic comparison for how GANs learn is a counterfeiter and a police officer. The counterfeiter wants to make false banknotes that the police officer cannot tell apart from real banknotes. The task of the police officer is to learn how to find the difference between false and real banknotes.

== 9040009b
To understand how GANs train, think of this experiment. The counterfeiter and the police officer are friends. They decide to improve their skills together. The counterfeiter makes some false banknotes and shows them to the police officer. The police officer examines them and tells the counterfeiter which banknotes look false and which look real, in the officer's opinion. The counterfeiter remembers this feedback and makes better false banknotes for the next round. At the same time, the police officer also learns: the officer remembers the false banknotes that the officer saw, and becomes better at finding the difference between real and false banknotes.

== 0f46ec7a
Think that this process repeats many times. What is the result? Each time, the banknotes of the counterfeiter become more difficult to tell apart from real banknotes. Also, the police officer becomes better and better at finding false money.

== 2bfea483
This is the important question to understand GANs: when can we say that the counterfeiter is really good at making false banknotes?

== cd0e4221
The answer: when the counterfeiter can trick a police officer who has much training. At the start of the experiment, the police officer possibly cannot find false banknotes well. Thus, false banknotes of low quality can trick the officer. But our final goal is a counterfeiter who makes banknotes that are the same as the original banknotes, also for a professional expert.

== 8ba2ff13
GANs are powerful, but they have some problems:

== 2237e326
<strong>Mode Collapse:</strong> the generator can learn to make only a small number of variations of outputs. It does not make samples with much variety.

== 75cad64e
<strong>Training Instability:</strong> the generator and the discriminator must stay in balance. If one of them improves too quickly, the other can fail to learn.

== cb6512cb
<strong>Vanishing Gradients:</strong> if the discriminator becomes too good, the generator can stop getting feedback that helps it to improve.

== e597e2a0
To solve these problems, researchers added different changes to the standard GAN framework:

== d4bb84bc
<strong>Wasserstein GAN (WGAN):</strong> it changes the loss function. This makes the training more stable and more efficient.

== 392100af
<strong>Conditional GAN (cGAN):</strong> it lets you control the generated output. It gives the model an additional input as a condition (for example class labels).

== 65181ac6
<strong>StyleGAN:</strong> it makes images of high quality, mainly synthetic human faces.

== efab7202
<strong>CycleGAN:</strong> it changes images of one type into images of a different type, without paired training data (for example, it changes images of horses into images of zebras).

== 4c34b3cb
GANs have many real-world applications, for example:

== cc0057f2
<strong>Image Synthesis:</strong> it makes realistic human faces, artwork and objects.

== d5ef5cff
<strong>Data Augmentation:</strong> it makes datasets for the training of machine learning models better.

== 1544f357
<strong>Style Transfer:</strong> it puts artistic styles on photos, or it changes features of images.

== fcccb202
<strong>Super-Resolution:</strong> it makes low-resolution images better, with more detail and clarity.

== 5d237930
<strong>Deepfake Technology:</strong> it replaces faces in videos with faces that AI made.

== 51d9a46f
GANs showed that an adversarial objective can make synthetic data that is very realistic. They are still important in areas such as image translation and synthesis that you can control. But their training is unstable, and they cover only part of the modes of the data. This helps to explain why people now often prefer other generative methods for general-purpose generation.

== 3414fa21
A real layer calculates <span class="math">Q</span>, <span class="math">K</span> and <span class="math">V</span> from the token vectors with learned matrices. It runs several of these heads in parallel, each on a smaller part of the vectors. Then it joins (concatenates) their outputs. Thus, multi-head attention is this function, some matrix multiplications and a reshape.

== 67cfeb04
A decoder makes one token at a time. Because of the causal mask, the keys and values of the earlier tokens never change. Thus, the decoder calculates them only one time and keeps them in a <b>KV cache</b>. Each new token calculates only its own query, key and value, and it attends to the cache. It does not run the full sequence again. The cost is memory. A model with the shape of Llama&nbsp;2&nbsp;7B (32 layers with a width of 4096, numbers with 16 bits) keeps

== 917ac283
Thus, a conversation of 4096 tokens needs 2 GiB of cache, in addition to the weights. This is why long contexts are expensive. It is also why newer models share keys and values between groups of heads (grouped-query attention). With 8 key-value heads of size 128, as in Llama&nbsp;3&nbsp;8B, the cache becomes 128 KiB for each token. Remember this when you run models locally, as in the Ollama exercise.

== 78966b40
To train a dense Transformer with <span class="math">N</span> parameters on <span class="math">D</span> tokens costs approximately <span class="math">6ND</span> floating-point operations. For GPT-3, this is <span class="math">6 \times 175 \cdot 10^{9} \times 300 \cdot 10^{9} \approx 3 \cdot 10^{23}</span>. Kaplan et al. (2020) found that the loss decreases as a smooth power law of model size, data and compute. Hoffmann et al. (2022) asked how to divide a fixed budget between <span class="math">N</span> and <span class="math">D</span>. They found that the models of that time were too large for the data that they saw. Their Chinchilla model has 70 billion parameters and was trained on 1.4 trillion tokens (approximately 20 tokens for each parameter). With the same compute, it was better than the Gopher model, which has 280 billion parameters.
